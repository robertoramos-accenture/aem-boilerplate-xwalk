# EDS Demo Site - AEM Content
This project implements a new Adobe Experience Manager (AEM) project, authored in Universal Editor and published to Edge Delivery.

## Prerequisites

- nodejs 20 or newer
- AEM Cloud Service release 2026.4 or newer

## Installation

```sh
npm i
```

## Linting

```sh
npm run lint
```

## AEM sync
```sh
aem up
```
